# Why 1634 was separate, and what is available

R1887 is Ferdinand's letter from Stuttgart, **28 October 1634**. It was excluded from the 1635/1640 key experiment because the original handoff explicitly selected the draft-assisted 1635 reconstruction and its 1640 transfer, and because the 1634 manuscript uses a visibly different repertoire. This was a sequencing decision, not a conclusion that 1634 cannot be solved.

## Images checked

All four images were already downloaded in the same private artifact directory as the other witnesses:

- `IMG_R1887_I9345_P1.png`: first body page, clear Latin mixed with cipher.
- `IMG_R1887_I9346_P2.png`: substantial cipher continuation with clear Latin islands.
- `IMG_R1887_I9347_P3.png`: short continuation and dated closing.
- `IMG_R1887_I9348_P4.png`: address/endorsement side.

This pass revisited all four. The actual writing includes numerous graphic signs, numbers, and repeated groups such as *xer*, *xir*, *ten*, and *tis*. They need a fresh transcription and assignment table. Superficially identical alphabetic code labels must not inherit the 1635/1640 values without evidence. The earlier "four pages" metadata does not mean four full pages of ciphertext.

## Catalog caution

The [DECODE catalog record](https://de-crypt.org/decrypt-web/RecordsView/1887), inspected 18 September 2026, says the cipher seems the same as a draft dated "1634-11-16". The known R954 draft is actually dated **1635-11-16** and uses the later repertoire. This catalog statement is not a verified 1634 plaintext witness. No corresponding 1634 draft has been identified in our inspected material. The saved record lists paper access, without the explicit transcription attachment available for R1889/R1890.

A fresh web fetch of the record via the web tool failed; the downloaded metadata and actual images remain the evidence used here. The shared [Cryptiana discussion](https://cryptiana.blogspot.com/2025/09/correspondence-between-emperor.html) still displayed no comments on this check. No full prior-publication audit or cryptanalytic attempt for R1887 is claimed.

## Practical route

The letter is a plausible separate target: appreciable ciphertext, repeated code groups, and clear Latin surrounding the encrypted passages. The clear writing on page 1 discusses Swedish affairs and correspondence; the ending on page 2 visibly mentions Nördlingen. These give subject context, not predetermined plaintext for the encrypted sections.

A productive attempt would first check attached material and published correspondence, transcribe the graphic symbols consistently, and compare the observed repertoire with the Brussels SEA key collection. It should then test assignments on repeated passages. We already have the images; the obstacle is reconstructing another cipher, not obtaining the target.

R953's attachment was rejected as a match for 1635/1640. It has a different alphabet and some pronounceable codes, but this does not either establish or exclude a match for 1634. No matching 1634 key has yet been demonstrated.
